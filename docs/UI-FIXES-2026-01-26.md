# UI Fixes Summary - January 26, 2026

## Overview

Comprehensive UI/CSS fixes and responsive enhancements based on browser console errors and user feedback.

## Issues Fixed

### 1. THREE.Material Color Undefined Bug ✅

**Problem**: Browser console showing `THREE.Material: parameter 'color' has value of undefined`

**Location**: `src/entities/ClaudeMon.ts:520` (createStatusRing method)

**Fix**: Added fallback to main color when statusColor is undefined:

```typescript
color: this.options.statusColor !== undefined ? this.options.statusColor : this.options.color
```

**Result**: No more THREE.js color errors in console

---

### 2. MCP/Plugin API 404 Errors ✅

**Problem**: API calls going to wrong port (4002 instead of 4003):

- `:4002/api/mcp/servers` → 404
- `:4002/api/mcp/installed` → 404
- `:4002/api/plugins` → 404

**Files Modified**:

- `src/ui/MCPMarketplaceModal.ts`
- `src/ui/PluginMarketplaceModal.ts`

**Fix**: Added environment-aware API_URL constant:

```typescript
const API_URL = import.meta.env.DEV
  ? '/api' // Proxied through Vite in dev
  : `http://localhost:${(window as any).VIBECRAFT_PORT || 4003}`
```

Replaced all hardcoded `/api/...` fetches with `` `${API_URL}/...` ``

**Result**: All API calls now route correctly to port 4003
